# 🎂 Age Calculator

A simple and clean Age Calculator built using **HTML, CSS, and JavaScript** that calculates your exact age in years, months, and days from your date of birth.

---

## ✨ Features

- Calculates precise age in years, months, and days
- Simple, clean, single-page interface
- Input validation (prompts user if date isn't selected)
- Responsive card-based design

---

## 🛠️ Tech Stack

- **HTML** — structure
- **CSS** — styling and layout
- **JavaScript** — age calculation logic

```bash

```

3. Select your date of birth and click "Calculate Age"
